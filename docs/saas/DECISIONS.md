# 已锁定决策

改这些必须先改本文并告知相关人。

## 产品

| 项 | 决定 |
| --- | --- |
| 仓库策略 | **控制面分仓**（B）；工作台少改、高频跟官方上游 |
| 注册 | **开放注册**，无邀请码 |
| 组织 | **仅个人组织**；不做工作室多人协作（P0） |
| 注册福利 | **不送积分** |
| AI 费用 | **平台代付 + 积分** |
| 充值 | MVP **人工/后台**；汇率可配（例：10 元 = 100 积分 → `cny_yuan_to_credits=10`） |
| 平台 Key | **全部后台配置**；用户不可见、SaaS 模式不填 BYOK |
| 扣费 | **凡打模型/供应商的请求都扣积分** |
| 隔离 | **强度 B**：只见自己的项目；路径前缀 + **对象存储 org/user 前缀** |
| 对账 | 积分流水 ↔ 工作台 `api_calls` 成本，用 `task_id` / `call_id` 关联 |
